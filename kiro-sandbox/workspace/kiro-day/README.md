# 🧛 Kiro Day Medellín 2026

¡Bienvenido a tu entorno de desarrollo!

Este es tu workspace **kiro-day**. Aquí puedes crear tus proyectos,
abrir una terminal (`Ctrl+ñ` / `Cmd+ñ`) y empezar a trabajar.

## Primeros pasos

1. **Inicia sesión en Kiro CLI** (device flow — abre la URL en tu laptop):

   ```bash
   kiro-cli login --use-device-flow
   ```

2. **Empieza a usar el agente:**

   ```bash
   kiro-cli chat
   ```

> El login usa device-code flow: se imprime una URL + código que abres en el
> navegador de tu laptop para autorizar. No necesitas navegador dentro del sandbox.

¡A construir! 🚀
